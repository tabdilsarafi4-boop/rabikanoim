# پنل مشتری روبیکا — نسخه مستقل

این بسته فقط شامل **پنل مشتری و فایل‌های لازم برای اجرای ربات روبیکا** است. پنل مدیریت، فایل PHP مدیر، رمز مدیر و سرویس مدیر در این بسته وجود ندارد.

## محتویات
- `panel.py`: رابط پنل مشتری
- `bot.py` و `login_worker.py`: منطق ربات و ورود/اتصال حساب روبیکا
- `supabase_store.py`: دریافت تنظیمات هوش مصنوعی از Supabase
- `docker-compose.yml` و `Dockerfile`: اجرای پنل مشتری روی سرور جداگانه
- `schema.sql`: ساخت جدول تنظیمات مرکزی در صورت نیاز

## راه‌اندازی
1. فایل‌ها را روی سرور مشتری قرار بده.
2. از `env.example` یک کپی به نام `.env` بساز.
3. در `.env` مقدارهای `SUPABASE_SERVICE_ROLE_KEY` و `PANEL_PASSWORD` را تنظیم کن. برای `RUBIKA_LOGOUT_PASSWORD` هم یک رمز قوی و جداگانه قرار بده.
4. اگر جدول `public.ai_settings` هنوز در پروژه Supabase ساخته نشده، محتوای `schema.sql` را در SQL Editor اجرا کن.
5. اجرا کن:

```bash
docker compose up -d --build
```

پنل روی `127.0.0.1:8080` در دسترس است. برای انتشار روی دامنه از reverse proxy و HTTPS استفاده کن؛ پورت را مستقیم روی اینترنت باز نکن.

## امنیت مهم
کلید `SUPABASE_SERVICE_ROLE_KEY` محرمانه است و باید فقط در فایل محیطی سرور باشد. اگر مشتری به فایل‌ها یا دسترسی سرور دسترسی دارد، ممکن است بتواند این کلید را استخراج کند؛ برای سرویس تجاری چندمشتری، راه امن‌تر این است که کلیدهای AI و دسترسی Supabase فقط روی سرور خود مدیر باقی بمانند و ربات از API واسط استفاده کند.

این بسته پنل مدیریت ندارد و تنظیمات مرکزی AI را خودش ویرایش نمی‌کند؛ فقط تنظیمات ذخیره‌شده در Supabase را می‌خواند.
