# دستیار هوشمند روبیکا (OpenRouter + Pollinations)

یک پنل وب کوچک که در آن کلیدهای متعدد OpenRouter و Pollinations، مدل‌های دلخواه، نمونه‌های سؤال و جواب برای لحن، شماره و کد روبیکا را وارد می‌کنی. بعد از ورود، ربات روی اکانت خودت پیام‌ها را می‌خواند، سبک نوشتنت را یاد می‌گیرد و با سرویس‌های OpenRouter و Pollinations جواب می‌دهد و در صورت خطا به کلید بعدی می‌رود.

مدل پیش‌فرض: `dots-studio/dots-3-note-preview:free` (از داخل پنل قابل تغییر است).

## راه‌اندازی روی سرور (برای کار ۲۴ ساعته)

1. یک VPS لینوکسی با Docker بگیر.
2. فایل‌ها را روی سرور بگذار و بساز و اجرا کن:
   ```
   docker build -t rubika-assistant .
   docker run -d --name rubika --restart unless-stopped \
     -e PANEL_PASSWORD='یک-رمز-طولانی-و-قوی' \
     -v rubika-data:/data \
     -p 127.0.0.1:8080:8080 \
     rubika-assistant
   ```
   بدون Docker: `pip install -r requirements.txt` و بعد `PANEL_PASSWORD=... python panel.py`
3. از کامپیوتر خودت یک تونل SSH باز کن و پنل را در مرورگر ببین:
   ```
   ssh -L 8080:localhost:8080 user@server-ip
   ```
   بعد برو به `http://localhost:8080`
4. در پنل:
   - کلیدهای OpenRouter و/یا Pollinations را وارد کن (هر کلید در یک خط)، مدل هر سرویس را دستی بنویس و «تست اتصال و کلیدهای API» را بزن. برای Pollinations از https://enter.pollinations.ai/ کلید بگیر.
   - شماره‌ات را بزن، کدی که روبیکا می‌فرستد را همان‌جا وارد کن (اگر رمز دومرحله‌ای داری، همان‌جا می‌خواهد).
   - ربات را روشن کن.

پنل خودش ربات را نگه می‌دارد و اگر از کار بیفتد دوباره راه می‌اندازد. با `--restart unless-stopped` حتی بعد از ریبوت سرور هم بالا می‌آید.

## امنیت

- پنل را بدون رمز و بدون HTTPS روی اینترنت باز نگذار. پیش‌فرض فقط روی localhost است. اگر می‌خواهی مستقیم در دسترس باشد، پشت Nginx/Caddy با HTTPS بگذار و `COOKIE_SECURE=1` را تنظیم کن.
- فایل‌های داخل `/data` (به‌خصوص `session.*` و `config.json`) معادل دسترسی کامل به اکانت و کلید توست. از آن‌ها بکاپ عمومی نگیر.
- پیام‌های چت‌ها برای تولید جواب به OpenRouter و ارائه‌دهنده‌ی مدل فرستاده می‌شود. مدل‌های رایگان ممکن است از داده برای آموزش استفاده کنند. چت‌های حساس را در «بلاک‌لیست» بگذار.
- از حالت «پیش‌نویس» شروع کن. وقتی از کیفیت جواب‌ها راضی شدی «خودکار» را روشن کن.
- ربات غیررسمی روی اکانت شخصی ممکن است خلاف قوانین روبیکا باشد.

## محدودیت‌ها و نکات فنی

- مدل‌های `:free` سقف درخواست دارند. اگر در لاگ خطای 429 دیدی، یعنی به سقف خورده‌ای.
- منطق پنل و لاگین با یک rubpy ساختگی تست شده، نه با خود روبیکا. اگر در نسخه‌ی rubpy تو متن پرسش شماره/کد فرق داشت و پنل گیر کرد، تابع `fake_input` در `login_worker.py` را ببین.
- اگر پیام‌ها دریافت نشد، تابع `extract()` در `bot.py` را با نام فیلدهای نسخه‌ی خودت تطبیق بده.


## قابلیت‌های نسخه‌ی توسعه‌یافته

- چند کلید برای هر سرویس؛ در صورت شکست درخواست، کلیدها و سپس سرویس بعدی امتحان می‌شوند.
- مدل OpenRouter و Pollinations جداگانه و دستی تنظیم می‌شود.
- نمونه‌های اختصاصی سؤال و جواب در پنل قابل درج است؛ اگر خالی باشد، یادگیری از تاریخچه مانند قبل انجام می‌شود.
- متن انتهای پاسخ قابل تنظیم است و با خالی گذاشتن فیلد، متن اضافه نمی‌شود.
- برای ذخیره یا جایگزینی کلیدها، کلیدهای جدید را هرکدام در یک خط وارد کن؛ اگر فیلد کلید را خالی بگذاری، کلیدهای قبلی حفظ می‌شوند.
